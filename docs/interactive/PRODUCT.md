# TailCache results explorer

## Platform and purpose

Standalone web document for the TailCache researcher to inspect the retained focused Task 12 results. The user requested a conclusion at every data point and interactive graphs showing any crossover. Read the local evidence without collecting new measurements.

## Evidence and constraints

Use all 132 workload forks from `evidence-archives/focused-rq-p99999-20261108-001/study.json`, which augments the original study without replacing it. Preserve individual pairs, warning flags, runtime groups, timing windows, measurement channels and ordinary/getUsing ownership contracts. Report p99, p99.9, p99.99 and p99.999. Explain the terms in-page and show extreme-tail sample support. Publish only the standalone results page to Vercel. No invented confidence intervals, pooled histograms or interpolated crossover threshold. A lower value in all three pairs is descriptive consistency, not statistical significance.

The output must open directly from disk, work without a server or network connection, and support both desktop and mobile. It must expose every timing channel, while defaulting to the research endpoints: saturated service and scheduled response. Exports must reflect visible comparisons. Existing raw evidence and AGY edits remain untouched.
