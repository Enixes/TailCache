## Prospective preparation contract

Keep120 one-second normal warmups, then run eight fixed one-second conditioning iterations using the actual measurement-mode/result path, followed by eight one-second analysed measurement iterations. Apply the same conditioning count to both recorders and every campaign/pilot/floor/supporting channel. Conditioning is fixed before collection and independent of latency, backend rankings or which individual rows fail. No adaptive stop or best-window selection is allowed. A new fork must complete all normal-warmup/conditioning/measurement phases; all their raw counters, histograms and logs remain retained with explicit phase/role metadata.

JMH will physically record16 measurement-mode iterations. Its worker sidecar labels the first eight CONDITIONING only when exporting after the fork's worker windows have finished, avoiding a new hot phase branch. The raw JMH16-iteration aggregate remains retained and is explicitly ineligible as the eight-iteration primary endpoint. Recompute histogram endpoints from the predeclared last eight, validating every conditioning and analysis histogram/count first. Diagnostic throughput/allocation summaries must similarly distinguish raw aggregate from analysis-window values. Compiler broad-profiler gates use only the declared eight analysis windows and retain the complete16-iteration raw counters. The unchanged80-ms total/10-ms individual limits apply to those eight analysis intervals; per-worker counters remain mandatory.

The every-operation worker similarly records eight conditioning windows before its eight analysis windows, using the same operation boundary. Export conditioning histograms separately and retain phase/index mappings; validate all phases. Compute phase classification after timing rather than adding a cache-operation branch. Functional/pause validation uses zero conditioning so its explicit injected first measurement remains unchanged; the full new harness still requires fresh source-matched functional and pause evidence.

No old file with eight raw measurements may be interpreted as an eight-plus-eight fork. Require matching explicit controls, raw iteration count and phase evidence. Missing, repeated, malformed or shifted conditioning rows fail closed. Host CPU settling uses the final ten seconds before analysed windows, naturally including the eight conditioning seconds; full-block memory, power, paging, containment and source rules remain unchanged. Failed conditioning-time host/integrity/churn demand must remain observable and cannot be deleted as a statistical outlier. Compiler activity during explicitly declared preparation is retained; any compiler violation in the eight analysis windows remains terminal.
