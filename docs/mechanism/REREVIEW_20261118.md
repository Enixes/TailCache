## Rechecked research evidence

The locality response-p99.9 reversal survives arithmetic and raw/source binding: four concentrated pairs favor Caffeine, four distributed pairs favor Chronicle. Actual frozen schedules agree with physical phase chronology; all 64 benchmark windows are serial/nonoverlapping. Repeated seeds use opposite backend order, and headroom confirmation uses a fresh seed/opposite order. This is stronger than the old point-specific order imbalance, but still only two repeated seeds and one host.

Cross-treatment logical operation/write counts match in every phase. Within each backend/seed, measured worker allocation differs by at most **0.000166 bytes/operation** between update sets, with most comparisons exactly equal. Realized common churn over all 64 forks is **99.9752–100.0310%** of its offered rate. Thus unequal admitted allocation volume does not explain the large locality contrast in these records. It still does not isolate object survival from locality/policy activity or measure which object types were promoted. Read materialization is an intentional library-contract difference, not something equalized away. Values are consumed into an exported checksum and final contents are checked; the measured ordinary-Chronicle allocation remains about 4122 bytes/operation at 4 KiB. An unused legacy caller-buffer local is not evidence of a guaranteed retained footprint; no inference relies on it. The measured Java remains unchanged to preserve qualification identity.

The full tails sharpen the interpretation: all four concentrated pairs favor Caffeine at response p99.9, but favor Chronicle atp99.99 andp99.999. All four distributed pairs favor Chronicle at all three. The winning backend therefore depends on the SLO percentile as well as update working set; no single backend uniformly dominates the tail. These correlated endpoints do not supply independent replications or a newly pressure-emergent threshold.

The larger-heap counterexample remains supported as an observed bounded result. At5% writes, Caffeine's total exposure decreases while p99.9 increases in both seeds; raw pause shapes differ, and the fresh1024 MiB pair is warning-free. This does not establish a universal tuning effect. At0.5%, the warning-free contrary30-second result remains. Longer-window seeds54831/54832 are different from the contrary short-window seed54842; a matched duration intervention was not performed.

Frozen model claims also remain limited: M1/M2/M3 give21/22 calibrated transport pair directions versus 22/22 for lower-total-GC. Broader envelopes improve descriptive numerical error, not universal accuracy or before-run prediction. A constant pilot quantile remains better for Chronicle alone in aggregate. ## Assessment

No defect changing the retained measurements or headline quantiles was found in this pass. The main response-locality finding is a defensible **warning-inclusive bounded exploratory result**. It does not resolve the original ordinary-service pressure crossover, a universal write threshold, exact lifetime/promotion causality, equal-total-memory savings or a precise cache selector. All original NO_GO/forecast/collector-failure records remain.

The previous verifier was too permissive to support a claim that arbitrary partial packages would be rejected; that claim is repaired and tested rather than glossed over. The remaining scientific limitation is clean independent replication, especially of the concentrated arm, plus an external arrival observer. Broad same-host midpoint searching is not needed to report the existing result. Author approval, contribution/literature assessment, final typesetting/licensing and a citable deposit remain publication work, not something this code review certifies.
