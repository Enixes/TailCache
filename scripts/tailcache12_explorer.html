    Read the result, keep the context

    A crossover means the same endpoint changes ordering between observed pressure points. An advantage already present at zero ballast is not a newly observed crossover. A mixed pair set does not become a consistent result by taking its median.

    • Ordinary get is the primary ownership contract. getUsing borrows a read buffer and always uses its own paired Caffeine controls.
    • Service measures operation completion minus actual start. Response measures completion minus intended arrival, including queue debt. Gap is time between completions.
    • Both payloads use a 512 MiB G1 heap, 32,768 resident entries and 32 MiB/s offered background allocation. Scheduled load is 50,000 requests/s.
    • Builds, durations and read contracts remain distinct. The graph never joins them into one continuous experiment.

    Evidence and uncertainty

    All 132 workload forks completed. Warnings remain attached. At p99.99, an 8 s response window has only 40 nominal observations in the upper 0.01%; a 30 s window has 150. Queued observations from one pause are correlated. More operation samples are not more independent forks.

    The original 8 s low-pressure response baseline is retained alongside the later 30 s batch. Pressure is common application ballast; heap occupancy is an observed backend-specific outcome.
